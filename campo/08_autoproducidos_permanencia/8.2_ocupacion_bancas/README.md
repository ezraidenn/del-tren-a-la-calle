# 8.2 Conteo de ocupación de bancas

- Tipo de fuente: datos autoproducidos
- Método: conteo de 15 minutos por banca en tres franjas (mañana, mediodía y tarde)
- Estado: simulado; la versión simulada está en `datos/simulados/` (ver [LEEME_SIMULADO.md](../../LEEME_SIMULADO.md)). Esta plantilla queda para un levantamiento real

Cada fila es un conteo. `id_banca` corresponde al inventario 8.1.
