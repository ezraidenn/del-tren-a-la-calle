# 8.1 Inventario de bancas y sombra

- Tipo de fuente: datos autoproducidos
- Método: recorrido a pie registrando cada banca, poyo o lugar para sentarse
- Estado: pendiente de levantamiento

`tipo`: banca, poyo, parada_con_asiento u otro. `sombra`: total, parcial o ninguna. `estado`: bueno, regular o malo.
